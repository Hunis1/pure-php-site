Installation:
1) Create folder with name "pure-php.local" at open server panel (or other tools for local development)
2) Copy all files from this repository from "pure-php" folder
3) Download database "pure-php.sql"
4) Import downloaded file from third step at your SQL (phpMyAdmin, MariaDb or other), with "Import" tool (it's in all the databases)

Usage:
1) Start your open server (or other tools)
2) Open browser page by url http://pure-php.local
